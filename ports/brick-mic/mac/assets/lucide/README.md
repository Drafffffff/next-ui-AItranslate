# 菜单栏辅助图标

选自[Iconify 的 Lucide 图标集](https://icon-sets.iconify.design/lucide/)，SVG来自[Lucide官方源文件](https://github.com/lucide-icons/lucide/tree/main/icons)。
本地保留原始SVG，运行时不请求网络。

主标识始终是自制的Brick掌机＋屏幕内麦克风，和应用图标一致，由Brand.swift绘制。Lucide只用于辅助标记：

- x：未连接
- circle-check：已连接
- audio-lines：正在说话
- ellipsis：识别处理中
- battery / battery-charging：掌机电量与充电状态

NSBezierPath按这些SVG的24×24路径绘制，采用macOS模板图标，自适应浅/深色菜单栏。版权与许可见LICENSE.txt。
