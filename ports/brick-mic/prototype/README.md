# Brick Mic 交互原型

在 Mac 浏览器打开 `index.html` 即可使用，无需安装依赖。也可以在仓库根目录运行：

```sh
python3 -m http.server 8767 --bind 127.0.0.1 --directory ports/brick-mic/prototype
```

访问 <http://127.0.0.1:8767/>。只监听本机。

这个原型不连接真实 Brick 或 Codex，不调用 ASR，不读取 Key、剪贴板或系统权限。右侧为模拟 Mac 输入框，左侧只有识别回显，没有掌机草稿编辑器。口述使用「示例口述」字段里的文字；复制/粘贴使用原型内部的模拟剪贴板。

## 建议试用顺序

1. 普通模式按住 A、松开，观察右侧填入但没有提交。
2. START 进入 Codex，选择任务。点右侧「备忘录」，再按 A，观察它主动定位回对应任务。
3. 十字键移动光标，点 L 锁定选字后移动，再按 B 删除；SELECT 中可撤销。原型为了鼠标操作允许锁定肩键，实机需按住肩键。
4. START 返回普通模式，确认 Mac 任务里的未发送文字保留；再次进入 Codex，按 X 提交。
5. 电源息屏，用场景测试产生通知，观察灯条和震动提示；唤醒后查看未读。
6. 断开模拟蓝牙后产生通知，再重连，观察补同步与一次汇总提醒。
7. 修改电量、充电状态，关闭 Codex，检查电量显示与模式入口变化。

模拟控制与消息只存在当前页面内存。刷新可清空试用数据。原型的定位/识别动画时长不代表真实设备响应时间。

完整设计见 [控制设计方案](../../../docs/BRICK-MIC-CONTROL-DESIGN.md)。
