# I 版菜单与肩键更新

本轮在家中电脑的目标 ARM64 SDK 中验证，不要求掌机联网。原 G 版及掌机文件均未更新。

## 操作说明

常用菜单中的键盘快捷键装饰、物品热键字母、通用列表热键列、制作说明、大地图键盘图例和高级背包小键盘示意已移除。功能按钮的确认/取消文字、物品名称、详情、地图内容、当前筛选和排序状态保留。屏幕键盘与动作面板内的重复说明也移除，操作提示集中在底部两行。显式打开的“掌机按键”帮助页仍可查看完整操作。

绘制修改只在 CDDA_BRICK=1 的图形版本生效，实际键盘绑定、物品热键和文本输入不被删除；非 Brick 界面保持上游显示。

## 按键分工

| 界面 | L / R | L2 / R2 | START |
| --- | --- | --- | --- |
| 游戏主视图 | 射击 / 装填 | 制作 / 高级背包 | 切换侧栏 |
| 物品栏 | 前栏 / 后栏 | 上页 / 下页 | 更多操作 |
| 制作 | 前分类 / 后分类 | 右侧材料上滚 / 下滚 | 更多操作 |
| 高级背包 | 固定左栏 / 固定右栏 | 上页 / 下页 | 更多操作 |
| 大地图 | 缩小 / 放大 | 上一层 / 下一层 | 光标快移（显示开关状态） |
| 自动屏幕键盘 | 光标左 / 右 | 清空 / 符号页 | 确认输入 |

高级背包 SELECT 改为选择背包区域；周围九格、穿戴物品、容器等从更多操作面板选择。面板还补齐了制作人员、配方已读状态、容器卸载、自动拾取等当前界面已注册的操作，避免隐藏键盘说明后失去入口。MENU+START 保存退出、MENU+FN1 制作等旧组合保留。

L2/R2 采用项目 tg5040 固件定义的 SDL 轴 2/5，加入按下/松键阈值和边沿触发；持续按住、轴值抖动不会重复执行。按钮 11/12 也提供同一映射。FN1/FN2 的旧按钮 9/10 保留。第二对肩键的真实编号仍需掌机联网后确认，此处 SDK 验证不能代替实物。

## 菜单按用途分组

大地图 MENU 首页“浏览地图”的第一项为“光标快移:开/关”。底栏说明当前每次光标移动几格，明确人物不随光标移动。状态来自游戏本身，键盘切换、读档或上一次开关都会同步；START 也能直接切换。笔记、危险标记及目的地归到“标记与路线”；天气、尸群、城市名称等归到“地图显示”。

主视图 MENU 的“行动”首页第一项是人物“移动模式”，打开行走、奔跑、蹲伏等选项，与地图光标快移分开。原来的制作可直接按 L2，也保留在“物品”页。

制作分为“常用制作、右侧材料、配方列表、配方整理”。物品栏分为“常用操作、容器与分类、列表浏览、数量与装备”；高级背包分为“搬运物品、物品区域、周围地面、列表与设置”。L/R 换组，方向选操作，A 执行。只显示当前界面可用的操作；没有操作的空格不绘制。上滚/下滚放在轮盘上/下位置，列表换分类或栏位在左/右，周围地面八项与八个方向对应。

制作右侧无法滚动的原因已定位：旧入口使用鼠标滚轮动作，游戏要求鼠标位于材料区域才响应。现在 L2/R2 和面板都发送专用的材料滚动动作，不依赖鼠标位置。MENU+上/下继续翻左侧配方列表，二者分工明确。默认大字体宽度不足以显示额外成品说明栏，因此不再给出无可见作用的“成品说明滚动”入口；宽布局实际显示该栏时才出现。

菜单组仅在上下文变化或可见栏位变化时重建；绘制每个操作格时不再重复生成整个动作列表。

## 验证凭据

最终程序、111 项实际游戏检查、58 项模拟休眠检查、源码重放和内存采样记录于 `build/cdda-i-port/validation/menu-scroll/results.json`。画面覆盖物品栏、制作、大地图、高级背包、排序列表、屏幕键盘和更多操作面板。对实际 SDL 截图逐像素比较：R2 改变右侧材料而左侧配方列表完全不变；L2 恢复原位置；面板按下方向再确认也执行同样滚动。地图开关后底栏发生预期变化，START 再切换后恢复原提示。人工检查分组、中文和布局。

最终程序 SHA256：`5798a3f3ca83ce2fad16213f48c29352373e0fa5bfd7f8fb6ba93d5d1887e859`。上一轮 83 项菜单检查及原始内存压力测试保留各自程序哈希；本轮仅引用实际复测的结果。

本轮游戏测试使用 700 MiB 容器限制且无交换内存，完成保存与正常退出。它是菜单改动回归验证，不是长期探索或应用最大内存证明。先前远距离生成压力测试属于此前内存优化程序，保留原程序哈希与证据，不冒充本轮程序的实机验证。

实体按键、音频出声、系统真实休眠和长期实机稳定性仍待验证。本轮产物是独立 I 版测试包，尚未安装到掌机。
