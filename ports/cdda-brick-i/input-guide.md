# I 版掌机按键说明（底部两行提示）

游戏内底部两行会显示当前界面可用的掌机按键。点按 MENU 查看当前菜单更多操作，L/R 换操作组，方向选动作，A 执行，B 返回。

## 物品栏与拾取

按 SELECT 打开物品栏。上下选物品，左右或 L/R 换栏；L2/R2 整页翻动；START 打开当前菜单更多操作。

- X：搜索，自动打开屏幕键盘。
- Y：收藏；拾取、丢弃等多选列表中变为勾选/取消勾选。
- A：普通列表确认；多选列表提交已勾选物品。
- SELECT：切换按分类选择模式。
- FN1：查看物品详情；FN2：展开或收起容器。
- MENU+FN1/FN2：多选物品数量减一/加一。
- 需要指定数量、跳到首末、切换分类视图等，用 MENU 动作面板。

## 制作

游戏中 L2 或 MENU+FN1 打开制作。上下选配方，左右切子分类。

- L/R：上一个/下一个大分类。
- L2/R2：滚动右侧材料、工具及要求说明；不会改变左侧配方。
- START：更多操作，不再重复“下一分类”。
- X：搜索；Y：进入或离开批量制作模式。
- SELECT：收藏配方。
- FN1：配方详情；FN2：相关配方。
- MENU+上/下：左侧配方列表上页/下页。更多面板分为“常用制作、右侧材料、配方列表、配方整理”，按 L/R 换组。
- 只有屏幕确实显示额外的成品说明栏时，才出现“成品说明”滚动组；目前默认大字体布局没有这栏。

## 高级背包

游戏主视图按 R2 打开高级背包，也可在 MENU 面板“信息”页选择。

上下选物品，左右或 L/R 切换左右栏，L2/R2 翻页；SELECT 把当前栏切到背包；START 打开更多操作。A 查看详情，X 搜索，Y 移动当前整叠物品，FN1 排序，FN2 容器详情。移动单件、指定数量或全部物品等操作在 MENU 动作面板中。

## 大地图

游戏中 FN2 打开大地图。方向移动光标，支持斜向。

X 搜索，Y 回到角色，L/R 缩小/放大，L2/R2（或 FN1/FN2）上一层/下一层，SELECT 查看笔记，START 切换“光标快移”。底栏及 MENU 首页都显示“光标快移:开/关”；选中这项时底栏会解释当前步长。开启后只改变大地图光标一次移动的格数，人物位置不变。

MENU 首页“浏览地图”第一项就是光标快移；其余按“标记与路线、地图显示”分组。添加笔记、标记危险、设置目的地、显示尸群、天气等入口在相应组内。搜索结果里 L/R 切结果。

## 输入文字或数量

搜索、输入数量等界面自动打开键盘。

方向选字符，A 输入，X 删除，Y 大小写，SELECT 空格，L/R 移动输入光标，L2（或 FN1）清空当前输入，R2 切换符号页。START 确认，B 取消本次输入。数字在第一行，标点在下面，右下角“符号”可换页。

MENU 可先收起键盘查看原界面；MENU+SELECT 可重新打开。手动打开的键盘用 B 收起，已输入的字符保留。当前支持英文、数字和 ASCII 符号，尚无中文输入法。

## 菜单组合键

先按住 MENU，再按另一按键：

- 上/下：上一页/下一页；左/右：首项/末项。
- X：清除筛选；Y：收藏。
- SELECT：开关键盘。
- FN1/FN2：多选列表数量减/加。

原来的键盘快捷键标注、列表热键字母和制作/大地图说明不再显示；可点击的确认/取消按钮保留文字。唯一的操作说明是底部两行掌机提示，随界面变化。更多动作由 START/MENU 面板列出，包括高级背包的周围九格、穿戴物品和容器选择。

L2/R2 按固件 tg5040 定义的 SDL 轴 2/5 接入，使用按下阈值、松键阈值及一次触发处理；按钮 11/12 也可触发相同操作。FN1/FN2 仍是旧映射的按钮 9/10。这些编号目前已在 SDK 模拟输入验证，实际硬件需待联网后确认。

仅在当前菜单支持该动作时生效。菜单里 START 不执行保存退出。游戏主视图仍用 MENU+START 保存退出，询问时 A 或 MENU+A 确认，B 或 MENU+B 取消。

菜单方向键长按连续滚动更快；切换界面会停止旧方向的重复输入。主视图 MENU 的“行动”首页第一项是“移动模式”（走/跑/蹲），与地图光标快移分开。这个操作改变人物移动方式，每次方向输入仍移动一格；它不是自动行走。原有组合键保留。

## 掌机休眠

短按电源键让掌机休眠，再按电源键唤醒，恢复到当前游戏、菜单或屏幕键盘。主游戏画面会先保存；保存失败取消休眠。菜单中保留内存状态，不写入正在编辑的内容。游戏忙于加载或运算时，会在下一次等待按键时处理休眠。MENU+Y 仍是让角色睡觉。

唤醒时重开声音设备，当前音乐可能从头播放；方向长按和残留按键会清理。休眠只保留通电内存，关机后通过正常存档读档；目前没有空闲自动休眠或休眠后自动关机。
