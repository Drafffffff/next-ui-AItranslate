Regenerate native 64px alpha masks with `node ports/pocketjs-brick/workshop/icons/generate.mjs` after `npm ci --ignore-scripts --prefix ports/pocketjs-brick/workshop`. Runtime recolors the masks using NextUI theme variables. No network is needed on the handheld.
