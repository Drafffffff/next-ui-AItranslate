# 固定 16 色的 8×8 像素素材

方法参考 Pixel Art Professional（MIT，来源与许可见 ../references/community.md），已适配到 `write_game.sprite_overrides`。

- 先确定轮廓和朝向：把人物主色块安排清楚，再用 1–2 像素表达眼睛、手脚或方向。8×8 不适合在每个区域铺满抖色和噪点。
- 使用透明色 0；主要形状与背景有明暗差，敌人、奖励和玩家的识别不能只靠微小色相差异。挑选 P8 已有颜色索引，不输出新的 RGB 调色板。
- 同一素材通常用主色、暗色、高光等少量颜色；阴影跟随一个明确光源。不默认沿整圈边缘都加阴影。可用轮廓增强小屏辨识度，但不要把小对象内部填黑到看不清。
- 抖色只用于较大的材质或阴影过渡；人物优先大色块。不要依赖半透明和自动抗锯齿，输出只有 0..f 的整像素索引。
- 原素材编号在读到当前项目后确定；改角色时复用这个角色已有 ID，不能挤掉别的对象。标题“蓝色机器人”与 `spr(id)` 及覆盖像素必须一致。
- 需要动画时，每帧独立占一个允许的 ID；节拍计时有界，在 `_draw` 选帧。图像变大不自动扩大碰撞框，碰撞尺寸由玩法决定并与可见轮廓对应。
- 16×16 不是一个 ID：`spr(32,x,y,2,2)` 使用 **32、33、48、49** 四个 8×8 格。要确认四格都在 32..63 范围内且不覆盖已有素材；每格分别提交覆盖。左上格不能放在 sheet 最右列。没有空余连续格时保留 8×8 或用多次 `spr` 组合。
- 像素行必须 8 行，每行 8 个小写 hex 字符；0 为透明。8 行 `00000000` 可以显式清空已有图像。省略覆盖或传空列表保留素材，不表示删除。

自查像素范围、实际 `spr` 编号、占用格子、轮廓、背景对比和动画节拍。当前工具没有观看 sprite 渲染结果或导入图片的能力，不声称已经视觉验证。

## 素材表达规则，避免装饰盖过信息

掌机库的Celeste Classic在`set_hair_color`用颜色显示剩余冲刺能力；Just One Boss用姿态、位置和等待表达下一次危险。可借鉴状态→视觉的映射：技能恢复亮色、空资源暗色，危险预告描边/闪烁，命中短暂变色，死亡改变姿态。配合形状/动画而非仅色相，让玩家在128×128里能分辨。

先列出实际需要的精灵和帧数再分配32..63：玩家待机/移动、不同职责敌人、目标、危险与地形。少量原创帧比空槽位引用和大量无规律随机像素更有效。背景控制对比，奖励和危险有不同轮廓；命中、拾取与升级粒子来自事件并有上限。HUD放恢复镜头之后，不能遮住入口/目标。参考不是原作素材包，不复制未提供的图像。
