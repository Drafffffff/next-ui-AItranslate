# 游戏库研究与生成Skill升级

日期：2026-10-02。用户反馈生成游戏质量差，需要从掌机已有PICO-8游戏提炼方法。此次直接研究设备上的卡带，不只整理API或另外写几个原创模板。

## 样本与证据

只读SSH调用设备现有pico8-data-extractor，提取18款卡带的Lua；17款审阅了指定机制的完整相关函数及调用上下文，Driftmania源码高度压缩，仅完成初步识别，未据此推断操控算法。没有修改游戏库卡带或用户项目。对全部18款实际卡带核对SHA256，并记录提取Lua的hash、字节数、LF行号、作者和原发布页。

结构化清单：[library-cases.json](../skills/pico8-game-dev/references/library-cases.json)。来源页面用于作者/原版追溯；算法判断依据本机固定卡带。提取源码留在被Git忽略的build研究目录；Skill不包含此次研究的原卡带、整份源码或素材。既有MIT/GPL社区参考和许可保留。

| 类型 | 源码研究对象 | 归纳重点 |
| --- | --- | --- |
| 平台动作 | Celeste Classic、To A Starling | 输入缓冲、离地容错、地面/空中控制、分轴碰撞 |
| 回合与解谜 | Porklike、Guncho、Woodworm | 合法动作事务、动画不重复消费回合、完整历史/环境恢复 |
| 落块与信息益智 | Pico Tetris、High Stakes、Mai-Chan's Sweet Buns | 横移重复与软降、候选旋转回退、可见线索与订单结算 |
| 赛车与物理 | Pico Off Road、Breakout Hero、Combo Pool | 惯性/滑动方向、顺序waypoint、运动线段碰撞、合成事件去重 |
| 战斗 | Just One Boss、Buns: Bunny Survivor | 出招时序与恢复、无敌反馈、有限波次 |
| 探索与关卡 | Dusk Child、Into Ruins | 场景完整状态、检查点、区域连接 |
| 3D | Wolfenstein 3D、Hungry Harry 3D、Pico Off Road | DDA深度、物体遮挡、有界透视世界、玩法与渲染分离 |

不把库里的原排名当作本次质量评分，不把源码观察当试玩评价。原作的实现也有近似和约束：例如Wolfenstein的物体中心列遮挡、原作地图/内存依赖、不同30/60 Hz参数，模块注明适配边界而不照抄。

## 进入Agent的方式

继续使用现有pico8-game-dev，每个项目默认使用核心Skill。新建/核心重做先读取library-patterns，选一个相应类型模块；已有项目局部改动按实际源码选择参考，不强制读完整模板。

新增按需模块：library-patterns、platform-feel、grid-turns、racing-physics、combat-design、level-design。3D/像素/声音方法补充到原模块，音乐仍渐进加载。构建脚本将模块加入真实read_skill工具枚举和资源hash清单；只有读取library-patterns时追加实际原发布页与函数行号，默认请求不包含研究语料。

生成重点是核心选择、可靠操作、可读反馈、空间/目标约束与失败恢复。针对既有失败加入对应源码推演：软降不能在重构中丢失，赛车触发区不能在墙里，地下室切换不能沿用地表碰撞图，拾取状态不能在回房时重置，随机雕刻不能破坏外墙，atan2方向要核对。

## 验证与后续质量对比

本次验证Skill格式、资源一致性、真实Pi工具的模块加载/来源返回、参考读取不修改当前项目、默认上下文保持有界，以及既有工具和示例回归。模拟模型响应只验证工具链，不能测量DeepSeek生成质量。当前宿主check_game提供真实P8语法/资源检查，不自动试玩。

后续可对相同模型配置/需求进行升级前后对比，记录完整需求、草稿、卡带hash、工具轨迹与用户试玩；不以生成源码行数或“工具调用成功”代替质量。第一组评估需求可采用：

| 请求 | 静态关键点 | 需实际试玩的体验 |
| --- | --- | --- |
| 做一个单屏冲刺平台，跳到终点，O跳X冲刺 | 输入请求只消费一次、边界碰撞、次数恢复、终点可达、重开清状态 | 短按/长按、落地前输入、冲刺方向是否可靠 |
| 做一个有撤销的推箱子，3个小关卡 | 目标层不丢失、完整快照、重开还原、不以随机墙冒充可解图 | 第一关教规则，后两关带来不同选择 |
| 做一个短赛道赛车，跑3圈 | 触发区可行驶、按序检查点、逆向不刷圈、贴墙可脱离 | 转向/制动、可理解的路线与完成反馈 |
| 做一个有两种招式的Boss战 | 预告/行动/恢复、一次受击、阶段清理、死亡优先 | 预告清楚、能应对、恢复提供机会 |
| 做一个有钥匙、出口和检查点的3D地牢 | 外墙闭合、钥匙依赖、DDA有界、遮挡、世界坐标/镜头一致 | 玩家能找路、目标明确、恢复不烦躁 |
| 修改已有落块游戏：加踢墙，其他不变 | 软降/锁定/连续清行保留、旋转失败回退 | 长按移动/软降与墙边旋转自然 |

先解决核心规则和手感，随后依据真实试玩反馈迭代。此次产出是有来源和适配方法的Skill升级；尚没有对生成游戏质量提升给出实测分数。
