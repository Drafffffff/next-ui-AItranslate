# Brick Mic 掌机交互

目标：拿起掌机即可说话。普通输入使用 Mac 当前输入框；Codex 模式绑定明确任务，口述完成只填入，X 才发送。普通模式显示口述回声，Codex 首页直接显示最新 AI 回复，文字光标和选区在 Mac 上。

Codex 的 X 发送对应消息输入框中的 Return；SE 换行对应 Shift+Return。发送由掌机操作，不在口述结束后自动触发。

## 每条链路

| 链路 | 操作 | 掌机展示 |
| --- | --- | --- |
| 普通口述 | 打开应用 → 在 Mac 选输入框 → 按住 A → 松开 | 正在听 → 正在识别 → 最近口述 |
| Codex 口述 | SR → 选任务 → A 口述 → X 发送 | 进入即看最新回复 → 录音/识别 → 自动展示口述结果 → X 发送后保留结果 → 新 AI 回复到达后展示 |
| 切换任务 | Y → 切换任务 → 选择 | 原任务的 Mac 草稿保留；新任务定位期间禁止编辑/发送 |
| 编辑文字 | 首页十字键移动，肩键+十字键选字，B 删除 | Mac 原生光标/选区；SE 以全选为第一项，随后撤销、重做、复制、粘贴、换行、查看口述、删除文字 |
| 阅读 | 选择任务即显示最新 AI 回复，单按 L/R 翻阅 | 首页 7 行正文；本地分屏读完才请求下一页，A 随时录音 |
| 审批 | 提醒 → Y → 待确认的操作 → 阅读 → 左右选 → A | 明确任务、操作、选择；默认拒绝，不将 A 录音变成批准 |
| 返回普通输入 | 首页 SR 切回普通输入 | 解除目标绑定，Mac 草稿保留 |
| 休眠 | 短按电源 → 按住 A | 保留连接，唤醒即录音；断连连续 5 分钟后深休用电源唤醒 |

## 页面职责

顶部使用用户提供的 SVG 话筒图标配合当前页面标题，使用系统文字色；首页只有模式/目标、电量、主要内容与动作。普通模式显示输入状态/最近口述；Codex 选中任务后直接显示最新 AI 回复，录音显示最近 2.4 秒实际麦克风音量波形，静音接近平线；识别期间显示相应状态；识别完成后自动展示本次口述结果供核对，X发送后保留，收到新的AI回复后切换。SE菜单提供查看口述/AI回复。输入框定位不会把已有正文替换成加载画面。Y 仅在 Codex 首页打开任务中心；普通输入首页隐藏并禁用 Y，只有 SR 可进入 Codex。SE 是文字编辑；SR 是唯一的模式切换键。任务中心按优先级列出待确认、选择/切换任务、提醒，不包含模式切换项。普通模式收到提醒仍可震动、闪灯；进入 Codex 后通过 Y 查看。

编辑和任务菜单分开，保留全部功能。B 在首页删除/取消，在子页返回；断连时不意外退出应用。MENU 退出应用。SR、Y、SE 和 X 只在首页生效，子页不响应隐藏快捷键；子页只使用底部当前显示的操作。

Codex 首页单按 L/R 前后翻阅最新回复，不发 Mac 编辑命令；L/R 与十字键同时使用仍选择 Mac 文字，释放肩键不会误翻页。实体 X/Y 按 NextUI tg5040 定义映射：X=摇杆按钮3，Y=按钮2；键盘预览的 X/Y 语义相同。

阅读页减少标题占用，从 4 行增至 7 行；菜单一次显示 5 项。颜色和字体继续取 NextUI 系统主题，不增加新配色、装饰图形或常驻应用标识。所有按键提示统一进入底部同一行：A说话/Y任务/SE编辑/SR普通或Codex，X发送仅在Mac当前任务输入框有未发送文字时出现，L/R阅读仅在正文超过一屏时出现，全部左对齐，按钮之间及按钮与说明之间统一8px间距，文字使用实际字宽，保持原字号；不可用动作隐藏。所有页面的按键操作提示只在底部同一排显示。SR=START，SE=SELECT。正文不再重复按键教学；上方仅保留目标、状态和回复页码；等待、权限和通知只在需要时展示。

## 状态护栏

- 录音和识别期间不接受任务、编辑、发送或审批操作；B 取消仍有效。
- 返回后需重新按 A 才录音，关闭子页不会同时触发录音。B 与 A/X 同按时 B 优先。
- 任务切换用目标 ID 和定位状态确认；未选择任务的 Codex 首页按 A 进入选择，不进行无目标录音。
- 列表按条目ID复用未改变的对象，底部按键行也按内容复用，避免每100ms状态轮询重建整行造成闪烁。每次重新排序以条目 ID 保持选中项。审批绑定当前请求 ID，更新/过期后回任务中心，不批准下一条。
- 普通输入的口述回声只在对应模式首页显示；Codex口述结束即在首页显示，SE可在口述与最新AI回复之间查看，Mac 上未发送内容不变。
- 回复绑定任务 ID，切换任务、切回普通输入、断开信任会清除旧任务正文；新一段回复到达时回到其开头。没有缓存回复时明确显示“等待回复”，不虚构历史。
- 静止像素不重复提交到屏幕，避免软件渲染每帧清屏造成闪烁；正文按内容缓存排版，跨页面返回直接恢复，不受输入框定位状态影响。任务、回复/口述、审批严格保持各自的归属。
- 蓝牙重连和恢复已选任务会直接带上最新回复，无需再发送“打开回复”命令；同页 L/R 滚动仅在掌机处理，不产生额外蓝牙数据。
- 蓝牙和 Codex 的运行状态保持来自 Mac 的真实状态，界面不将识别成功表述为已填入或已发送。

本轮仅重做掌机应用和所需状态字段，浏览器原型保持原样。

## 编辑快捷键与详情底部精简

- L3（SDL按钮9）输入空格，R3（按钮10）在普通模式按回车、Codex模式插入换行，Codex发送仍只由X触发。首页与编辑菜单可用，录音/识别、定位中、未授权、未选任务及其他菜单不输入。每次按下只触发一次，按住不重复。Mac键盘预览Z/C模拟L3/R3。
- Codex详情不常驻B删除提示，B快捷删除保留，SE菜单新增删除文字入口。全选排在编辑菜单第一项。
- X发送依据Mac验证过的目标输入框是否有非空白文字显示，不依据掌机口述回声。Mac只传是否有草稿这一布尔值，不回传草稿正文。连接且选中Codex任务时每0.5秒读取验证过的缓存输入框，无法绑定时查找间隔至少5秒；状态变化才发蓝牙消息。普通模式和录音/定位中不检测。
- L/R提示只在当前正文超过7行，或AI回复跨服务分页时显示，快捷键不增加到常驻详情底部。

提醒列表按独立事件 ID 复用行，同一任务的多个事件不共用行标识。普通首页、任务中心、任务列表、提醒、编辑、阅读及审批仅在可见内容变化时更新；新消息正常更新并保留当前选中项。打开应用/重连同步历史提醒时静默回执，实时新提醒仍震动、闪灯。

## 2026-10-02：任务中心与回复刷新

Y 直接打开平铺的任务列表，移除“切换任务”和“任务提醒”二级列表。审批待确认时保留置顶入口；任务行右侧按主题色显示未读数（超过99显示99+）。上下浏览，任务超过一页时左右翻页，A选择，B回首页。状态更新按任务ID保留选择位置。

Mac从完整未读记录计算每个任务的气泡；任务页有变化即下发，没有变化不重复发送。收到新AI回复时以任务、轮次、更新时间和内容生成稳定版本标识，掌机切回AI回复；正文相同的新轮次也能刷新。录音、识别、审批和菜单保持当前操作；回到任务首页时展示最新回复。仅在回复已排版显示后发送已读回执，回执绑定具体版本；旧回执不会清除新回复或其他任务的未读。蓝牙送达ACK与已读回执仍分离，重连不重放震动、闪灯或编辑命令。

## Mac菜单栏

主图标始终使用与应用图标相同的Brick＋屏幕内麦克风标识，状态变化只替换右侧辅助符号：×未连接、圆形勾已连接、声波录音、…识别中。连接时显示掌机电池与百分比；充电为闪电电池。未连接不显示历史电量，未知显示—%。浅/深色及菜单选中态由原生模板图标适配；连接状态内保持104pt宽度，不因百分比位数变化移动旁侧菜单项。点击/右键原菜单行为保持。

电量继续用现有BLE遥测，无新扫描、网络图标请求或刷新定时器。记录、结束、识别完成、连接/断开和电量事件刷新图标；相同展示状态复用既有图像。辅助图标选自Iconify的Lucide集合，SVG与许可证本地随包分发。

菜单栏电量采用紧凑“电池＋百分比”分组，百分比不添加占位空格，仅保留原生图像/文字间距；左侧品牌/状态到电池的间距较大。固定宽度由菜单项本身承担，避免为了稳定宽度拆散电量分组。
