01

整体规则

先建立一张共同的“地图”。后续讨论改动时，可以精确到某个场景、某一层、某个按键，而不只说“菜单不方便”。

当前场景＋当前输入层＋按键 / 手势＝实际操作与底部提示
场景

主视图 → 专用界面

主视图面向人物行动；物品栏与拾取面向列表选择；制作同时包含左侧配方与右侧材料；高级背包面向两栏搬运；大地图面向光标浏览；文字与数量输入面向编辑。

输入

普通按键 → MENU 组合 → 临时界面

直接按键处理常用动作。按住 MENU 再按其他键，处理组合操作。动作面板、屏幕键盘或帮助打开后，按键优先作用于这层，原界面的方向键与操作会被接管。

入口

两个动作入口，有不同的内容

主视图 A：打开游戏自带的动作菜单。点按 MENU：打开我们适配的动作面板，按用途分组、方向选动作、A 执行。菜单里的 START 通常也打开该面板；大地图 START 用来切换光标快移。

反馈

底部两行是持续可见的操作说明

普通界面列出当前映射；按住 MENU 显示组合键；动作面板第一行显示选择与执行方式，第二行解释当前动作或状态。常用菜单原有的键盘快捷键装饰已经隐藏；主动打开的掌机按键帮助仍保留。

生命周期

电源键处理整台设备的休眠

主视图先保存再休眠，保存失败则取消；菜单和输入界面保留内存状态。唤醒恢复原界面并清除积压按键。角色“睡眠”和系统“休眠”有不同入口。

这套交互的共同约定：A 执行 / 确认，B 返回 / 取消，方向键处理当前焦点，L/R 在许多列表中换分类或栏位，L2/R2 处理独立的翻页或说明滚动。具体例外在第 05 节单独对照。
02

按键解释器

选一个场景，再切换输入层。点击按键，查看它作用于哪里、产生什么结果。这里是映射说明与画面示意，不是可运行的游戏。自动键盘实际属于文字输入场景；下方所选场景表示它确认或取消后返回哪里。

画面和按键分区为说明示意，不代表掌机外壳的精确布局。点按下面的按键查看职责，不执行游戏动作。

作用对象
当前行为
退出 / 后续

MENU 的两种手势：点按并松开，打开或收起动作面板；先按住，再按另一键，执行组合操作。组合已被使用时，松开 MENU 不会额外弹出动作面板。键盘或帮助显示时，点按 MENU 会先收起它。

04

更多动作如何放进菜单

常用动作走直接按键，较多或较少使用的动作进入分组面板。每页最多八项；超过八项会拆页。方向选中对应位置，再按 A 执行。

轮盘位置、条件显示和页码记忆

右侧上滚 / 下滚分别在上 / 下；列表前栏 / 后栏或前分类 / 后分类在左 / 右；首项 / 末项在左上 / 右上；高级背包的“周围地面”八项与八个方向对应。其他组按代码中的优先顺序填入轮盘，未全部采用空间方向对应。

面板会过滤当前菜单没有注册的操作，没有动作的格子不绘制。制作默认大字体布局不显示额外成品说明栏，因此不提供该栏的滚动入口；该栏实际可见时，才增加“成品说明”组。下面的分组目录表示现有配置，具体条目由当前菜单能力决定。

点按 MENU 可以保留当前面板页；在普通菜单里按 START 则从面板首页打开。主视图的四页位置会在进入并退出专用界面后保留。大地图 START 是光标快移开关，不能按普通菜单的规则理解。

05

职责与例外，一眼对照

最容易混淆的是 L/R、L2/R2 和 START。它们在不同界面有不同职责。点击表格中的任意映射，可以跳回相应场景查看。

普通按键层 · 主要场景（键盘列指自动输入键盘）

手机上横向滑动查看完整表格。“—”表示没有直接映射，或取决于当前菜单是否支持。MENU 组合键与动作面板内的按键分工，请在第 02 节切换输入层查看。

A 的两个“动作菜单”

主视图 A 打开游戏原生动作菜单；MENU 打开我们适配的动作面板。在动作面板里，A 才是执行当前选中动作。高级背包 A 查看详情，Y 搬运整叠。

人物速度与光标步长

人物移动模式包含行走、奔跑、蹲伏等，位于主视图“行动”首页。地图光标快移改变的是大地图光标一次走几格，位于“浏览地图”首页；此开关不移动人物。

左侧列表与右侧材料

制作 L/R 换大分类，左右方向换子分类，MENU+上/下翻左侧配方；L2/R2 单独滚动右侧材料。上下方向仍用于选择配方。不能把两边滚动当作同一个功能。

自动键盘与手动键盘

自动输入键盘的 B 取消当前输入，START 确认。手动打开的键盘 B/MENU 仅收起，已经输入的字符保留。自动键盘被 MENU 收起后，经 MENU+SELECT 重新打开会走手动模式；编辑光标和清空仍要求当前输入框支持。

保存退出有入口限制

主视图 MENU+START 发起保存退出并询问确认；主视图动作面板里 START 也可发起。普通菜单的面板 START 只是收起面板，不保存。数量和文字输入时 START 是确认输入。

长按并不都是快速移动

方向键长按会重复输入；菜单重复比人物移动更快。地图的光标快移是另一个独立开关。L2/R2 按下一次触发一次，持续按住不会连续重复。场景切换或唤醒会清理旧方向，避免人物多走一步。

06

把改进意见放到具体位置

用“场景 → 输入层 → 按键 / 入口 → 当前问题 → 希望行为”来描述。意见会整理成可复制的文字；这里不会修改游戏，也不会自动发送任何内容。

也可以在按键解释器中点击“以这个位置记录改进意见”，自动填入位置。

整理后的意见


版本边界基于当前独立 I 本地版本。111 项实际操作检查和 58 项模拟休眠检查已通过；实体 L2/R2 映射与系统真实休眠仍待掌机确认。此文档不会更新或安装游戏。
当前未覆盖的能力屏幕键盘只有英文、数字与 ASCII 符号，尚无中文输入法；没有空闲自动休眠、自动关机或关机后恢复菜单。系统音量 / 亮度快捷键尚未接入。
可继续讨论的位置按键命名与分工、菜单排序、动作入口、焦点位置、提示优先级，以及返回、取消、保存和恢复之间的边界。第 06 节的意见模板适用于这些方向。
